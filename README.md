# Differentially-Private-Data-Synthesizer
This project implements a privacy-preserving synthetic data generator using differential privacy (DP), ensuring data confidentiality.The tool takes real datasets as input and produces statistically similar synthetic data while mathematically guaranteeing that no individual's private information can be reverse-engineered.
